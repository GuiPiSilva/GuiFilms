# PiresFilms — Site oficial

Landing page de Guilherme Pires para serviços de filmagem, fotografia, vídeos empresariais e produção audiovisual.

## Visual
- Identidade preto e dourado
- Layout responsivo para celular, tablet e computador
- Seções Início, Sobre, Serviços, Portfólio e Contato
- Três imagens ilustrativas em estilo fotográfico
- Formulário de orçamento que prepara mensagem para WhatsApp

## Como executar
Abra **index.html** em um navegador. O HTML já possui CSS, JavaScript, logo e imagens incorporados e não exige instalação de dependências.

## Como editar contatos
Localize `window.PIRESFILMS_CONFIG` perto do final do arquivo `index.html` e configure:
- `whatsapp`: número no formato internacional, só dígitos
- `email`: e-mail comercial
- `instagram`: endereço completo do Instagram

O número de WhatsApp incluído corresponde ao contato comercial informado para a PiresFilms.

## Como publicar na Vercel
1. Importe este repositório no [Vercel](https://vercel.com/new).
2. Use **Other** como framework (site estático).
3. Deixe o diretório raiz como `./` e inicie o deploy.
4. Adicione o domínio próprio em *Settings → Domains*, se desejar.

## Observações
As fotografias presentes no layout são **imagens ilustrativas**, não trabalhos documentados da PiresFilms. Substitua-as por material próprio ao publicar seu portfólio real. O repositório mantém o nome histórico `GuiFilms`, mas a marca exibida é **PiresFilms**.
